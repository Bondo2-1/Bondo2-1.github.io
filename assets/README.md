# Portfolio assets

This directory is the source of truth. `npm run assets:prepare` copies runtime files into `public/assets/` and creates responsive WebP illustrations. Default widths are 640px and 1200px; the layered experience artwork uses 480/560/800/960px variants from its manifest entries. Development and production builds run preparation automatically.

- `illustrations/`: eleven original transparent PNGs generated with the built-in OpenAI image model. Seven are displayed. The first robot, original automation modules, United Elite processor, and original SDN containers are archived. The hero uses `hero-n8n-robot-v2.png`; United Elite uses `automation-card-player.png` and `sales-bank-comparison.png`; SDN uses the approved `sdn-office-developer.png`. Artwork is conceptual, not customer data or photographs of deployments.
- `prompts/`: exact generation prompts and input-reference roles, retained locally and excluded from the public repository.
- `manifest.json`: illustration IDs, source files, prompts, and public output names.
- `layers/`: normalized SVG masks derived from the approved experience artwork. The original pixels stay intact: CSS translates only the three logo-card cutouts and the bank cloud. Retain complete square canvases and update masks when changing those originals.
- `reviews/experience-concepts/`: approved drafts, image inputs, and official logo references. Source PNG hashes match the installed originals. Internal prompt and approval records remain local and ignored.
- `reviews/sdn-office-concept/`: approved office-developer draft and character reference. Internal prompt and approval records remain local and ignored. Installation changes only the SDN image and its alternative text; role details and layout remain intact.
- `brands/`: the new official n8n logo, downloaded from the [n8n brand guidelines](https://guidelines.n8n.design/logo) on 15 November 2026. The current charcoal hoodie uses the [white-and-pink SVG](https://guidelines.n8n.design/downloads/logo/lockup/n8n-logo-white-accent.svg); the earlier dark-wordmark SVG is retained. Both originals are unmodified.
- `references/`: supplied character and n8n logo references, plus the first generated Docker character. The final About cutout is `illustrations/about-docker-engineer.png`; its two prompts are recorded together. These stylized characters are not photographs of Mohamed.
- `fonts/`: locally hosted Latin fonts and their SIL Open Font License texts. Sources: Fontsource Anton, Inter Variable, and IBM Plex Mono npm packages, pinned by the lockfile.
- `resume/`: the supplied résumé PDF, copied unchanged with permission. Its phone number is also shown as a telephone link below the hero location, as requested on 15 November 2026.
- `taste/`: unmodified system, motion, and word-highlight assets from design-taste-frontend 2.5.1. Do not edit these files to satisfy checks; page overrides belong in the application stylesheet.

After changing an image, retain its original filename or update the manifest and typed portfolio references together. Keep copy and labels in live HTML. The About character's Docker hoodie and hero robot's n8n hoodie are user-requested branding; interface icons still use Phosphor. The hero robot's `preserveCanvas` manifest flag keeps its eye and chest overlay coordinates aligned. Its eyes blink every two seconds, follow fine pointers, and stop under reduced motion, offscreen, or in a hidden tab. The pause button was removed at the user's request. Without JavaScript the character remains visible with open centered eyes.

Approved experience objects drift vertically by 4–8px over 6.5–8 seconds. Figures, held cards, thought dots, and the sales form stay still. Reduced motion shows both complete illustrations at rest. Animation pauses offscreen and in hidden tabs; no additional pause control was added. The form appears in the illustration. Its summary and purpose are rendered as HTML from typed data.
